# SEO 2차: 작성자·E-E-A-T·JSON-LD 통합

- 상태: 완료

## 목적

글 화면에 표시되는 작성 주체와 `BlogPosting.author`를 하나의 검증 가능한 엔티티로 통합하고, 작성자 프로필과 편집 정책을 연결한다.

## 구현 게이트

- 실존 개인이나 의료 검수자를 임의로 만들지 않는다.
- 현재 운영 주체인 Clinic GEO 편집팀과 SUMMITFEED 관계만 표시한다.
- 기존 아티클 JSON 원문은 일괄 덮어쓰지 않고 중앙 정본에서 기존 별칭을 통합한다.
- 공개 글의 화면 작성자, 메타데이터 작성자, JSON-LD 작성자가 같은 이름과 URL을 사용한다.

## 구현 결과

- 중앙 작성자 정본: `lib/authors.ts`
- 작성자 프로필: `/authors/clinicgeo-editorial-team`
- 공식 이름: `Clinic GEO 편집팀`
- 상위 운영 조직: `써밋피드(SUMMITFEED)`
- 기존 JSON의 작성자 별칭은 원문을 변경하지 않고 렌더 단계에서 공식 엔티티로 통합한다.
- 보조 `MedicalWebPage`를 포함한 콘텐츠 Schema의 작성자·발행자도 같은 엔티티로 정규화한다.
- 모든 글에 작성 주체, 발행 주체, 확인일, 작성 기준과 편집 정책 링크를 표시한다.

## 인계

- 운영 배포는 이 작업에 포함하지 않았다.
